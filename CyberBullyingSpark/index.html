Observations

  • Using Apache Spark distributed learning makes the model more accurate and faster
  • Using spaCy wasn't an ideal solution as different methods that support distributed learning exist
  • A cyber-bullying system would work more efficiently if its distributed

Limitations

  • Limited understanding of sarcasm
  • Multi-label handled using separate models
  • spaCy is not distributed

Future Improvements

  • Use BERT or DistilBERT for better context understanding
  • Try using UrbanDictionary API for slang language understanding
  • Spark NLP instead of spaCy
  • Real-time processing using Kafka
  • Deploy as a service
