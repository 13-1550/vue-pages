Observations

  • Using Apache Spark distributed learning makes the model more accurate and faster
  • Using spaCy wasn't an ideal solution as different methods that support distributed learning exist
  • A cyber-bullying system would work more efficiently if its distributed

Tests and trials

  • Testing data

    when testing the data the relsut was unrelistically high, which lead to makeing further verfication of the data and it was found that the testing data did not converet correctly and thus the trained data was compared to itself resulting in innacurate evaluation

  • Spark NLP

    When testing Spark NLP, instead of using a combination of spark and spaCy, the session broke and the server kept getting disconnected from spark. This does not mean that spark nlp isn't a good solution but rather that the computing power was not efficient enough for the job

Limitations

  • Limited understanding of sarcasm
  • Multi-label handled using separate models
  • spaCy is not distributed

Future Improvements

  • Use BERT or DistilBERT for better context understanding
