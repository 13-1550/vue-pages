Cyberbullying Detection System

AI + NLP + Distributed Processing

📌 Overview

This project detects harmful online content using Natural Language Processing and distributed computing. It classifies text into hate speech, violence, and harmful intent.

⚙️ Architecture

spaCy → Apache Spark → ML Pipeline → Logistic Regression

🧠 Technologies

  • spaCy (text preprocessing)
  • Apache Spark (distributed processing)
  • TF-IDF (feature extraction)
  • Logistic Regression

📊 Results

High accuracy across multiple categories of harmful content.

⚠️ Limitations

  • Limited understanding of sarcasm
  • Multi-label handled using separate models
  • spaCy is not distributed

🚀 Future Improvements

  • Use BERT for better context understanding
  • Real-time processing using Kafka
  • Deploy as a web/mobile app
